# v0.1.0

**Release Date:** 2026-05-18

Initial release of Market Strategy Engine - a strategic capability gap analysis system for competitive market intelligence.

## Highlights

- Strategic capability gap analysis system for competitive market intelligence
- Single-market and multi-market analysis with weighted gap computation
- Dark-themed HTML reports with vendor color visualization

## Features

### Core Analysis Engine

- **Gap Analysis**: Compute weighted gaps between your product and competitors based on segment-specific capability weights
- **Readiness Scoring**: Calculate segment readiness with four levels:
  - Ready (80-100): Competitive in segment
  - Adjacent (60-79): Minor improvements needed
  - Partial (40-59): Significant work required
  - Distant (0-39): Major investment needed
- **Priority Ranking**: Automatically rank gaps by weighted importance for roadmap planning
- **Effort Estimation**: Estimate implementation effort based on gap type and size

### Multi-Market Analysis

- Analyze a vendor's position across multiple product markets simultaneously
- Cross-market insights identifying strongest/weakest markets and segments
- Portfolio-level strategic planning support

### Data Model

- **Analysis**: Top-level container with market, segments, vendors, weights, and scores
- **Market**: Hierarchical structure with categories and capabilities
- **Capabilities**: Three gap types - product, structural, perception
- **Segments**: Target market segments with characteristics
- **Vendors**: Competitor profiles with optional color for visualization
- **Weights**: Segment-specific capability importance (must sum to 1.0)
- **Scores**: Vendor capability ratings (0-10 scale)

### CLI Commands

| Command | Description |
|---------|-------------|
| `mse analyze` | Run single-market gap analysis |
| `mse multimarket` | Run cross-market portfolio analysis |
| `mse validate` | Validate analysis JSON files |
| `mse generate-schema` | Generate JSON Schema files |

### Output Formats

- **Summary**: Human-readable text output (default)
- **JSON**: Full analysis results for programmatic use
- **Priorities**: Tabular priority list
- **HTML**: Dark-themed visual reports with:
  - Segment readiness cards
  - Strategic priorities table
  - Competitive comparison
  - Gap analysis details
  - Vendor color legend

### Validation

Comprehensive input validation including:

- Required field checks
- ID uniqueness verification
- Reference integrity (weights, scores, focusVendorId)
- Weight sum validation (must equal 1.0 per segment)
- Score range validation (0-10)

### JSON Schema

- 16 embedded JSON schemas for all model types
- Programmatic access via `schema.Get()` function
- CLI generation with `mse generate-schema`

## Installation

```bash
go install github.com/grokify/market-strategy-engine/cmd/mse@latest
```

## Quick Start

```bash
# Validate your data
mse validate analysis.json

# Run analysis
mse analyze analysis.json

# Generate HTML report
mse analyze analysis.json --format html --output report.html

# Multi-market analysis
mse multimarket --focus my-company market1.json market2.json --format html -o portfolio.html
```
